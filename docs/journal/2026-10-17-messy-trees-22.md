# 2026-10-17: Messy trees, t-string fidelity and the review decisions

Follows [2026-10-17-audit-22.md](2026-10-17-audit-22.md). The review decided:
- the hybrid semantics and the single-segment default are the provisional direction for
  0.2, with `docs/SEMANTICS.md` a proposed specification;
- `glob` follows symlinks only on request;
- no release or version bump yet.

It asked for the value proposition to be tested on realistic, heterogeneous layouts (with
ambiguity, optionality, collisions and irregular naming), and for t-string fidelity to be
confronted directly.

Labels: **[Fact]**, **[Measured]**, **[Interpretation]**, as in the earlier entries.

---

## Symlinks

- **[Fact]** `glob` defaults to `follow_symlinks=False`. The walk starts at the expression's
  fixed prefix (its head and leading literal segments), which is resolved like any path.
  Below it, symlinked directories are not descended into, and `kind=` judges a link as
  itself.
- **[Fact]** Starting below the literal prefix matters. With the first version of the
  change, `P("/tmp/x") / ...` put every literal component in the walk, so any symlink in
  an absolute root made `glob` return nothing silently (for example macOS
  `/var → /private/var`).
- **[Fact]** `recurse_symlinks=True` follows links inside a `SubPath`, independently of
  `follow_symlinks`, and skips directories already on the current path, so cycles end.
- **[Fact]** The docstring calls the option a traversal policy, not a sandbox or
  protection against races.

## Inference on real and synthetic trees

**[Fact]** `docs/journal/scripts/2026-10-17-messy-trees.py` infers a schema for each tree.
It then checks:
- every observed path matches a layout;
- `glob` finds every observed path again through its own layout;
- each `optional` flag agrees with a brute-force check;
- there are no duplicate patterns.

Trees used:
- **Real:** `/usr/share/zoneinfo`, `/usr/share/doc`, `/etc`, the Playwright browser
  install, the giacometti repository, a CPython 3.14 install, `/usr/include` and
  `/usr/lib/python3`.
- **Synthetic:** Hive partitions with Spark part names, ML runs with missing checkpoints
  and one irregularly padded epoch, a dated photo library with sidecars, an
  ImageNet-style class tree, FASTQ lanes, log rotation, versioned releases with
  platform-specific artefacts, and terminfo-style letter directories.

**[Measured]** Defects found, before the fixes:

| defect | where it showed |
|---|---|
| `optional` wrong in both directions | 13 of 75 layouts in site-packages, 54 of 142 in `/usr/share/doc`, 13 of 28 in the browser install |
| one pattern listed several times (`{dir}/{name}` twice) | site-packages, `/usr/share/doc` |
| a stray literal beside a `{stem}.parquet` map | Hive partitions |
| `IMG_{img:d}.xmp` beside `IMG_{img:04d}.JPG` | photos, because the `.xmp` values all lacked a leading zero |
| one `epoch_7.pt` turned `epoch_{epoch:03d}` into a `str` field | ML runs |
| `S{s:d}/S{s2:d}_...` with `s2` always equal to `s` | FASTQ, ImageNet |
| `pkgs/{a,b,c}/{a,b,c}.txt` stayed literal | one-off file names per directory |

**[Fact]** Causes and fixes (`src/wend/infer.py`):

- **Optional flags.**
  - *Cause:* sibling clusters that flatten to the same pattern each judged optionality
    over their own directories, and overlapping patterns match directories outside a
    layout's provenance.
  - *Fix:* `optional` is now a property of the pattern. It is true when some observed
    directory matching a prefix of the pattern contains none of its paths. It is computed
    by `_mark_optional`, which walks each pattern down the observed tree with the segment
    matcher, shares prefix frontiers between layouts, and verifies by rendering. The
    segment matcher alone accepts `00` for `{n:d}`; Hypothesis found that case.
- **Duplicates and stray literals.**
  - *Cause:* lone directories and files were grouped separately from an existing map at
    the same position.
  - *Fix:* a map now absorbs similar directories and same-extension files beside it, and
    all qualifying directory clusters at a position join one map.
- **Padding.** Equal-width digit runs wider than one digit read as `0Nd`.
- **Irregular names.** Same-skeleton names are split by format spec (`_partition`), so
  `epoch_7.pt` becomes its own layout.
- **Repeated fields.** A field always equal to an earlier one becomes the same parameter,
  given three distinct values, or two over four paths. Misfiled paths then fail `check`.
- **One-off names.** Directories holding only one-off file names compare by extension.

**[Measured]** After the fixes, every tree above reports 0 uncovered paths, 0 paths `glob`
misses, 0 `optional` disagreements and 0 duplicate patterns. Inferred schemas:

| tree | paths | layouts |
|---|---:|---:|
| Hive partitions | 47 | 1 (`warehouse/events/year={year:04d}/month={month:02d}/day={day:02d}/{stem}.parquet`) |
| ImageNet-style | 9 | 1 (`train/n{n:08d}/n{n:08d}_{n3:d}.JPEG`) |
| FASTQ | 12 | 1 (`fastq/S{s:d}/S{s:d}_L{l:03d}_R{r:d}_001.fastq.gz`) |
| ML runs | 43 | 4, including `epoch_7.pt` and `best.pt` as their own optional layouts |
| zoneinfo | 506 | 13 |
| `/usr/include` | 4244 | 124 |
| CPython install | 4806 | 614 |
| `/usr/lib/python3` | 2952 | 451 |

**[Measured]** Inference takes about 34 µs per path in `bench/bench.py`, up from about
24 µs. The difference is the pattern-based `optional` check. The CPython install takes
0.37 s.

**[Fact]** Terminfo-style directories, where each letter holds its own name families
(`a/att{n}`, `b/bvt{n}`), still produce one layout per family. The families share no
skeleton, so nothing merges them.

## Bidirectional APIs

- **[Fact]** `Lens(in/{a}/{b}.txt → out/{a}-{b}.txt)` reported `lossless` while mapping
  `in/x-y/z.txt` and `in/x/y-z.txt` to the same path.
  - *Fix:* a lossless lens now checks that each forward result maps back uniquely. It
    raises `AmbiguousMatchError` where two sources would share a target
    (`src/wend/_lens.py`).
- **[Fact]** A `Match` with no bindings (a literal or fully bound expression) had length 0
  and was falsy, so `if expr.match(path):` read as no match.
  - *Fix:* `Match.__bool__` returns `True`, as for `re.Match` (`src/wend/_match.py`).
- **[Fact]** `{stem}.{ext}` on `tool-1.0.tar.gz` has three readings, and `glob` raises
  `AmbiguousMatchError` for the whole walk. The message now says to bind a parameter or
  constrain one with `choices=` or `type=` (`src/wend/errors.py`); `choices={"tar.gz",
  "zip"}` resolves it.
- **[Fact]** Patterns have no alternation, so `app.log.{k}` and `app.log.{k}.gz` need two
  expressions.

## t-string fidelity

- **[Measured]** `docs/journal/scripts/2026-10-17-tstring-diff.py` renders 54 template and
  value pairs both as an f-string passed through `PurePosixPath` and with wend. 40 agree.
  Each of the 14 differences is a structural case that `docs/SEMANTICS.md` §4.1 lists:
  - an empty head value is the empty path;
  - after the head, a parameter is one segment;
  - a segment cannot vanish or climb;
  - a formatted field cannot contain `/`;
  - path positions take only paths;
  - `bytes` are not text.
- **[Fact]** Before this change, the probe also found an inconsistency: `t"data/{x}"`
  rejected `x=3` while `t"data/{x}.csv"` formatted it. A declared
  `Segment("n", type=int)` therefore could never render.
- **[Fact]** A segment position now formats a non-path value as an f-string formats `{v}`.
  `bytes` stay invalid, and head and `SubPath` positions still require `str` or
  `os.PathLike` (`_segment_text`, `src/wend/_expr.py`). Matching a typed segment inverts
  the formatting. Polars lowers integer columns at segment positions
  (`src/wend/frame.py`).
- **[Fact]** `P("/srv/static") / P(name).with_suffix(".png")` rendered
  `name="../../etc/passwd"` as `/srv/static/../../etc/passwd.png`. The parameter headed
  its own expression, so it kept path semantics through the deferred operation after
  being joined below the base.
  - *Fix:* `_join` now re-applies the operations to the parameter as a segment, as §2
    requires.
  - *Fix:* invalid bindings inside a deferred operation stay `InvalidBindingError`.
  - *Test:* `test_bindings_cannot_escape_a_literal_base` checks containment for random
    terms with operations. It finds the bypass when the fix is reverted.
- **[Fact]** The reference evaluator treated only syntactically empty left operands as
  keeping the head position, while wend's normal form also knows that
  `P("a").parent` and `x.relative_to(x)` are `.`. §2 now defines statically empty terms
  by static segment counts, and the reference follows that definition.
  - *Evidence:* the three contract properties passed two runs of 20,000 examples each.

## Answers to the two review questions

- **[Interpretation]** *Does wend preserve t-string semantics?* For the text of every
  interpolation, yes. Conversions, format specs, nested specs, `{x=}`, and formatted
  values at segment positions match Python's formatting. For structure, no, by design:
  §4.1 lists every case, and each one would otherwise change a path's segments.
- **[Interpretation]** *Is inference useful beyond the designed examples?* On data
  layouts, the schemas above are what a practitioner would write by hand, and the
  repeated-field and outlier rules turn `check` into a consistency test. On code and
  system trees, inference gives 2–34 paths per layout (giacometti 2.3, `/etc` 6.2,
  `/usr/include` 34) with overlapping patterns. That
  makes it a description of the tree more than a specification of it.

## Current State

- `glob` starts at the expression's literal prefix and, unless `follow_symlinks=True`, does not descend symlinked directories or classify links by their targets below it; `recurse_symlinks=True` follows links in a `SubPath` with cycle detection (`src/wend/_fs.py`)
- `infer` computes `optional` by walking each layout's pattern down the observed tree with shared prefix frontiers and render verification (`_mark_optional`, `src/wend/infer.py`)
- `infer` splits same-skeleton names by format spec (`_partition`), reads equal-width runs as `0Nd` (`_int_spec`), merges every qualifying directory cluster at a position into one map, and binds always-equal fields to one parameter (`src/wend/infer.py`)
- `tests/infer_test.py` checks `optional` against a brute-force oracle and the absence of duplicate patterns for Hypothesis-generated trees with padded and multi-run names
- A lossless `Lens` raises `AmbiguousMatchError` when a forward result does not map back uniquely (`Lens._target`, `src/wend/_lens.py`)
- `Match` is truthy for every successful match, including matches with no bindings (`src/wend/_match.py`)
- Segment positions format non-path values with `format(v, "")`, reject `bytes`, and match typed segments by inverting that formatting (`_segment_text`, `src/wend/_expr.py`; `_field_values`, `src/wend/_match.py`)
- `_join` re-applies deferred operations to an AUTO head parameter as a segment when the expression is joined below a non-empty term (`_head_param`, `src/wend/_expr.py`)
- `tests/contract_test.py` defines statically empty terms by segment counts (`static_len`) and checks containment below a literal base for random terms with operations (`test_bindings_cannot_escape_a_literal_base`)
- `wend.frame` casts integer columns at segment positions to strings, with null and choices checks (`src/wend/frame.py`)
- 173 tests (104 test functions) pass on Python 3.14.6 and on Python 3.15.0b4, and pyright 1.1.414 reports 0 errors on `src/wend`
- `docs/journal/scripts/2026-10-17-messy-trees.py` reports 0 uncovered paths, 0 `glob` misses, 0 `optional` disagreements and 0 duplicate patterns for five synthetic layouts and for any directories given as arguments

## Missing

- No alternation or optional pieces in patterns — `app.log.{k}` and `app.log.{k}.gz` need two expressions
- No `glob` mode that reports ambiguous paths and continues — one ambiguous path raises `AmbiguousMatchError` for the walk
- No generalisation across sibling directories whose children share no skeleton or extension, such as terminfo letter directories

## Divergence

- `pyproject.toml` declares version 0.1.1 while the public API differs from the 0.1.1 release on PyPI, as listed in `docs/MIGRATING.md`
